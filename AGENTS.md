# Instrucciones para agentes

## Inicio del trabajo
- Leer `CONTEXTO.md` y `README.md` antes de modificar el proyecto.
- Revisar los archivos existentes y respetar los cambios del usuario.
- Comunicarse en español, con explicaciones claras y breves.

## Desarrollo
- Usar HTML, CSS y JavaScript puro, sin Vue ni otros frameworks.
- Mantener una estructura sencilla y evitar dependencias innecesarias.
- Mantener el sitio estático y compatible con GitHub Pages. Usar rutas relativas para recursos internos que funcionen también bajo la subruta del repositorio.
- Crear un sitio minimalista, rápido y adaptable a celulares y computadores.
- Usar HTML semántico, navegación por teclado y colores con contraste legible.
- Definir los colores con variables CSS para facilitar ajustes.
- Usar `paleta colores.png` solo como referencia cromática. Su contenido no es información autorizada para el sitio.
- No inventar credenciales, especialidades, servicios, precios ni datos de contacto de Fabiana. Identificar como provisional cualquier contenido de ejemplo.
- Trabajar en incrementos concretos que el usuario pueda revisar en el navegador.
- No publicar el sitio sin una instrucción del usuario.

## Verificación
- Verificar los enlaces e interacciones afectados por los cambios.
- Revisar la adaptación a pantalla pequeña y la ausencia de desbordamiento horizontal cuando se disponga de un navegador.
- Informar qué se verificó y cualquier limitación o pendiente real. No afirmar comprobaciones que no se realizaron.

## Mantenimiento de documentación
- Actualizar estos documentos como parte del trabajo, sin pedir al usuario que lo solicite cada vez.
- Registrar en `CONTEXTO.md` las decisiones confirmadas, cambios de alcance, pendientes relevantes y estado actual.
- Mantener en `AGENTS.md` las reglas duraderas de colaboración y desarrollo.
- Mantener en `README.md` la estructura real del proyecto y las instrucciones comprobadas para ejecutarlo y revisarlo.
- Distinguir propuestas de decisiones aceptadas. No convertir sugerencias del agente en requisitos confirmados.
- Sustituir información obsoleta y evitar duplicar el historial del chat o documentar cada ajuste menor.
- No guardar secretos ni información sensible en estos archivos.
